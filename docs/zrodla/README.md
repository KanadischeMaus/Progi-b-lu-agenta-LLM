# Teksty źródeł (PDF)

Tu trzymamy pełne teksty pozycji z `docs/literatura.bib`. Agent czyta z nich fragmenty, na które się powołuje, zamiast cytować z pamięci.

- Nazwa pliku = klucz z `.bib`, np. `starzyk2017needs.pdf`.
- Pliki PDF z tego katalogu są w repozytorium jako zwykłe pliki (bez Git LFS), żeby agent pracujący na klonie mógł je czytać. Prawa autorskie mają wydawcy, dlatego repozytorium musi pozostać prywatne.
- Plik większy niż 50 MB zgłoś autorowi przed dodaniem.
- Pliki spoza bibliografii: `magister_szablon.pdf` (szablon pracy WMiFS 2025).
- Pozycje otwarte (arXiv, ACL Anthology, eLife, Frontiers) można pobrać bezpośrednio. Pozostałe przez Bibliotekę PRz (dostęp do IEEE Xplore, Springer, Nature).
