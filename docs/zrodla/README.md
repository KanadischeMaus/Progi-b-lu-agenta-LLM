# Teksty źródeł (PDF)

Tu trzymamy pełne teksty pozycji z `docs/literatura.bib`. Agent czyta z nich fragmenty, na które się powołuje, zamiast cytować z pamięci.

- Nazwa pliku = klucz z `.bib`, np. `starzyk2017needs.pdf`.
- Repozytorium musi być prywatne (prawa autorskie wydawców).
- Pozycje otwarte (arXiv, ACL Anthology, eLife, Frontiers) można pobrać bezpośrednio. Pozostałe przez Bibliotekę PRz (dostęp do IEEE Xplore, Springer, Nature).
